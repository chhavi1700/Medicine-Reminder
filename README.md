# Medicine Reminder App  

A cross-platform mobile application built using React Native and Expo that helps users manage their daily medications with timely reminders and an intuitive interface.  

## Features  

- Schedule and manage medicine reminders  
- Receive push notifications at the right time  
- View daily and weekly medication plans  
- Add, edit, and delete medicines  
- Secure local storage using AsyncStorage  
- Cross-platform support (Android, iOS, Web)  

## Tech Stack  

- React Native  
- Expo  
- React Navigation  
- AsyncStorage  
- Expo Notifications API 

## Installation  

git clone https://github.com/chhavi1700/Medicine-Reminder.git  
cd Medicine-Reminder 
cd Mdicine-Reminder-App
npm install  

## Running the App  

npx expo start  

Then:  
- Press `a` for Android  
- Press `i` for iOS  
- Press `w` for Web  

Or scan the QR code using the Expo Go app.  

## Known Issues  

- Notifications may not trigger correctly in background on some devices  
- Data is stored locally and not backed up
